# HAKI Studio

Editor web/PWA enfocado en mockups y diseño de productos.

## Funciones
- Importación de mockups, fotos, PNG/JPG/WebP/SVG.
- Capas, orden, bloqueo y visibilidad.
- Mover, escalar, rotar, voltear y sesgar.
- Texto, formas y pincel.
- Modos de fusión para integrar estampados con la tela.
- Brillo, contraste, saturación y blur con filtros Fabric.js/WebGL.
- Zonas de impresión y máscaras.
- Perspectiva rasterizada de cuatro esquinas.
- Guardado local mediante IndexedDB y proyectos JSON.
- Exportación PNG/JPG hasta 4x.
- PWA instalable.

## Despliegue
Aplicación estática, sin backend. Configura el directorio raíz del hosting como `studio` y no uses comando de build.
